# Machine Learning Models

This folder is intended to store trained machine learning models.

## Current Model

The project uses:

- K-Means Clustering

## Machine Learning Type

Unsupervised Learning.

## Features Used

The clustering algorithm uses:

- Annual Income
- Spending Score
- Purchase Frequency
