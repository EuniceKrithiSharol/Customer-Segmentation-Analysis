# Customer Dataset

This project uses a simulated customer behavior dataset generated using Python.

## Dataset Features

The dataset contains the following features:

- Customer ID
- Age
- Annual Income
- Spending Score
- Purchase Frequency

## Purpose

The dataset is used to identify meaningful customer groups using unsupervised machine learning techniques.

## Data Generation

Customer data is generated programmatically using NumPy. This allows the project to demonstrate the complete customer segmentation workflow without depending on external datasets.

## Future Improvements

Future versions of this project can integrate real-world customer transaction datasets and customer demographic information.
